# S100 + L515 真机 Adapter

该链路用于 WHEELTEC S100 与 RealSense L515。S100 提供串口控制和轮速反馈，
L515 提供 RGB-D；推荐通过 ROS 2 `slam_toolbox` 生成地图位姿和占用图。

```text
S100 反馈 ─────────► 轮速里程计 ───────┐
L515 深度 ─────────► 2D LaserScan ─────┼─► slam_toolbox
L515 RGB-D ─────────────────────────────┘        │
                                                ▼
                                  NavigationFrame ─► core
core 相对位姿 ─► A* 分段路径 ─► S100 低速控制
```

算法只面对统一接口；ROS、串口和 RealSense 代码都位于
`adapters/s100_l515/` 与 `adapters/realsense/`。

## 安装

L515 支持固定在 librealsense 2.54.1 系列，避免升级到已移除 L515 支持的版本。
首次创建环境并构建 RSUSB 用户态后端：

```bash
micromamba env create -f slam/s100_l515/environment.yml
micromamba activate robot-nav-slam
python -m pip install -e '.[visualization]'
hardware/realsense/build_rsusb.sh
slam/s100_l515/setup_usb_permissions.sh
```

最后一条命令安装 WSL 设备权限规则，需要一次 `sudo`。已有环境可同步：

```bash
micromamba env update -n robot-nav-slam \
  -f slam/s100_l515/environment.yml \
  --prune
```

## 连接设备

使用 `slam/s100_l515/run.sh` 启动时，脚本会在 Windows 侧识别并转发 L515 与
S100 串口；首次共享会弹出 UAC，由用户确认。已经手动转发时可设置：

```bash
export ROBOT_NAV_SKIP_USB_PREPARE=1
```

如果 UART4 和 UART1 两个 CH9102 同时连接，应明确选择控制口的 Windows
BUSID：

```bash
# Bash
export ROBOT_NAV_S100_BUSID=3-1

# Fish
set -x ROBOT_NAV_S100_BUSID 3-1
```

BUSID 重新插拔后可能变化。排错时分别检查：

```powershell
usbipd list
```

```bash
lsusb
ls -l /dev/serial/by-id/ /dev/ttyUSB* /dev/ttyACM*
```

Windows UAC 负责 USB 共享，WSL udev 规则负责设备权限；不要用 root 运行整个
导航程序。USB 2 与 USB 3 都能使用，USB 2 下彩色流为 `640×480@30`、深度流为
`320×240@30`。

## 标定相机

相机固定后标定一次；安装位置改变后必须重做。标定会左右旋转并向前移动约
0.20 m，执行前清空周围至少 0.5 m，并准备独立断电手段。

```bash
micromamba activate robot-nav-slam
slam/s100_l515/run.sh \
  python -m robot_nav calibrate-s100-l515 \
  --enable-motion
```

程序使用 Motion Module 判断静止和重力方向，用深度拟合高度与姿态，再结合
RGB-D 视觉运动和 S100 里程计估计平移与 yaw。结果默认保存到
`data/s100_l515/extrinsics.json`，导航时自动读取。

自动标定不可用时，至少用 `--camera-height-m` 提供手测高度；其他外参可用
`--camera-forward-m`、`--camera-left-m`、`--camera-yaw-deg`、
`--camera-pitch-down-deg` 和 `--camera-roll-deg` 覆盖。

## 预检与导航

第一次先让驱动轮离地运行预检；该模式只发送停止命令：

```bash
slam/s100_l515/run.sh \
  python -m robot_nav s100-l515 \
  --slam \
  --preflight-only
```

随后可用随机评分检查扫描、规划和运动反馈：

```bash
slam/s100_l515/run.sh \
  python -m robot_nav s100-l515 \
  --slam \
  --target "门口" \
  --debug-random-score \
  --enable-motion
```

随机模式不调用 VLM，也不能识别目标。正式搜索先执行 `opencode auth login`，
再去掉 `--debug-random-score`。场景搜索增加：

```bash
--search-mode scene --target "洗手间"
```

Rerun 默认开启，可用 `--no-rerun` 关闭；有多台相机时使用
`--camera-serial <SERIAL>`。

## 两种地图来源

- 带 `--slam`：ROS 独占相机，`depthimage_to_laserscan` 与轮速里程计共同送入
  `slam_toolbox`；这是推荐的导航模式。
- 不带 `--slam`：Python 直接读取相机，用反馈里程计累计局部深度地图并由本地
  A* 规划；仅适合小范围排错。

SLAM 参数位于 `slam/s100_l515/slam_toolbox.yaml`，深度扫描参数位于
`slam/s100_l515/depthimage_to_laserscan.yaml`。L515 视场远窄于 360° 激光雷达，
地图稳定性依赖相机安装、环境纹理和轮速反馈质量。

该链路不是动态障碍安全系统。首次标定和运动必须有人能够立即断电。
