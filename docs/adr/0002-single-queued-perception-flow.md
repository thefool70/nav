# 只维护当前异步视觉队列流程

架构整理后，命令行与 Python 调用共用当前异步视觉队列流程，保留物体搜索、场景搜索和随机评分调试模式。删除同步观察、到达后视觉确认及持续本地检测中断运动的专属分支，不继续维护平行的导航流程。

这项取舍减少入口和状态机中的分支，但不再兼容旧同步观察器调用方式。当前历史物体定位使用的 VLM 检测、YOLO/SAM2 及其定位计算仍保留；物体停靠命令成功即完成、场景返回拍摄位姿即完成等当前行为保持不变。核心仍可根据显式输入计算决策，不因此直接依赖队列、线程或模型。

本轮已按此方向实施：命令行与 Python 调用共用 `perception.SemanticPerception` 的
异步队列流程，同步观察器、最终确认与运动中断分支及其失效占位文件已删除。
历史物体定位所需的 VLM 检测、YOLO-World 与 SAM2 保留在
`perception/object_localizer.py`、`adapters/yolo_world.py`、
`adapters/sam2_segmenter.py`。
