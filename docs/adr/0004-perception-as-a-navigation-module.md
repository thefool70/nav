# 语义感知独立组织，调用输入显式传递

感知与搜索核心并列，负责逐图采集、FIFO 分析、评分与线索交付和历史物体定位。
它不控制底盘、不修改 `SearchState`；运行层传递感知增量，由搜索核心归并状态。

`perception/semantic_queue.py::SemanticPerception` 统一管理快照提交、模型线程、
暂停与关闭。`snapshot_store.py` 集中 RGB-D 内存快照与历史帧恢复，`analyzer.py` 集中单图
输入、模型协议、提示词与解析。`object_localizer.py` 集中历史定位的掩码/框选择、
深度与射线计算；HTTP 与本地模型进程仍由 Adapter 接入。快照同时服务扫描队列与历史定位，由感知队列统一持有；未命中或定位完成后释放。
大块图像有容量上限，日志与 Rerun 直接接收事件，不作为算法传递图像的中介。

启动时把同一个固定搜索目标传给感知会话和导航循环。采集调用同时传入帧与冻结的
`CaptureContext`，评分调用明确提供地图坐标系。用参数代替事先设置的隐含上下文，
减少调用顺序依赖；代价是调用点必须明确携带输入。任务、锁和待分析覆盖仍只由
原队列维护，不新增线程、任务状态或生命周期管理器。

待分析覆盖用于避免重复采图，只有有效分析后的覆盖才标为已检查。当前任务失败、
迟到结果、目标处理期间暂停，保持原有处理顺序。退出时释放内存快照，不自动续跑；诊断记录独立保存。
